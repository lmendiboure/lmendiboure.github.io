SITESENSE GUARD 4 — TECHNICAL NOTE
Revision 2.2 — 18 June 2026
Status: current technical note

1. PURPOSE
SiteSense Guard 4 is a compact monitoring gateway intended for temporary or semi-permanent deployment in technical rooms and sheltered construction-site areas. It records particulate concentration (PM2.5), temperature and relative humidity. It can provide a local alarm and forward records to the SiteSense Cloud service.

2. MEASUREMENT AND LOCAL DECISION
PM2.5 is sampled every 10 seconds. The local alarm becomes active when the 5-minute rolling average exceeds the configured PM2.5 threshold. Temperature and humidity are recorded but do not directly trigger the local alarm in the standard configuration.

The local alarm logic executes on the device. Loss of Internet connectivity does not disable this local alarm. The device stores one-minute records locally for up to 72 hours and uploads stored records after connectivity is restored.

3. REMOTE DATA
When connected, the device forwards a status package to SiteSense Cloud every 15 minutes. A status package contains the latest one-minute record, alarm state and device-health information. Failed uploads are retried every five minutes. The documentation does not specify a guaranteed maximum end-to-end latency between a physical event and its visibility in the cloud dashboard.

4. CONNECTIVITY
Bluetooth Low Energy is available for commissioning for ten minutes after boot. A wired dry-contact output is provided for a local indicator or supervisory input. The cloud communication technology used by the standard Guard 4 variant is not specified in this note. Guard 4C is a different product variant and includes an LTE-M modem.

5. INTEGRATION
Cloud data can be exported using the SiteSense REST API when the customer has an active Integration subscription. BACnet and Modbus are not supported directly by Guard 4. The dry-contact output is a signalling output only.

6. SAFETY LIMITATIONS
The alarm relay is rated 30 V DC / 1 A maximum and is not a safety-rated output. SiteSense Guard 4 is not certified as a safety instrumented function. Emergency shutdown, evacuation release, fire protection or other life-safety functions shall not depend solely on SiteSense Guard 4.

7. ENVIRONMENTAL CONDITIONS
Operating temperature: -10 °C to +45 °C.
Ingress protection: IP54.
Outdoor installation is permitted only in a sheltered position protected from direct rain, standing water and prolonged solar exposure.

8. SOFTWARE AND UPDATE
Firmware packages are cryptographically signed. Automatic firmware installation occurs only while the unit is externally powered. Battery-backed operation permits monitoring and local alarming but postpones automatic firmware installation until external power returns.

9. CLOUD DATA RETENTION
The standard SiteSense Cloud plan retains uploaded one-minute records for 12 months. Local 72-hour storage is independent of cloud retention.

10. IMPORTANT INTERPRETATION NOTE
The presence of a technical capability in this document does not imply that the capability is suitable for every operational or safety-critical use. System-level suitability must be assessed for the intended application.
