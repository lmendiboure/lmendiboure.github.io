# Questions à tester avec un LLM

Utilisez uniquement la note `sitesense-guard-4-technical-note.txt` comme source technique. Pour chaque réponse du LLM, vérifiez la preuve dans le document.

1. Le SiteSense Guard 4 continue-t-il à déclencher une alarme locale lorsqu'Internet est indisponible ?
2. Peut-on installer le produit sur une façade extérieure exposée directement à la pluie ?
3. Le relais peut-il être utilisé pour commander automatiquement l'arrêt d'urgence d'une machine ?
4. Quel protocole radio le Guard 4 standard utilise-t-il pour communiquer avec le cloud ?
5. Le produit supporte-t-il BACnet ou Modbus directement ?
6. Combien de temps au maximum faut-il pour qu'un dépassement PM2.5 soit visible dans le cloud ?
7. Un client sans abonnement « Integration » peut-il nécessairement exporter les données via REST ?

Pour chaque question, classez la réponse du LLM :
- correcte et explicitement démontrée ;
- plausible mais non démontrée ;
- contradictoire avec la note ;
- impossible à établir avec la note.
