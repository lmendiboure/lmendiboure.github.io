# TD1 — Consignes de rendu

- **5 pages maximum** hors éventuelles annexes.
- Répondez à **chaque question Q1 à Q18**, dans l'ordre.
- Une réponse peut être concise ; privilégiez les faits, les résultats de vos essais et les arguments qui justifient votre conclusion.
- Utilisez des tableaux lorsque cela simplifie une comparaison.
- Citez les sources techniques utilisées (documentation constructeur, base officielle, page d'outil, etc.).
- Une réponse générée par un assistant IA n'est pas une source.
- Vous pouvez joindre quelques captures utiles en annexe, mais une capture ne remplace pas une analyse.
