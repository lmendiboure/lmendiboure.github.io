# TD1 — Consignes de rendu

- Un rapport par groupe.
- 5 pages maximum hors liste des sources.
- Répondre explicitement aux 18 questions, dans l’ordre Q1 à Q18.
- Les réponses peuvent être courtes lorsqu’une observation suffit ; elles doivent être développées lorsqu’une justification ou une décision est demandée.
- Les tableaux sont encouragés pour comparer plusieurs résultats.
- Conserver les URL des pages, documentations et images externes utilisées.
- Une réponse d’un assistant IA n’est pas une source technique.
- Une capture d’écran peut illustrer une réponse, mais ne remplace pas l’analyse.
- Pour Shodan : rester strictement sur les informations affichées par le moteur de recherche et les sources publiques ; ne jamais tenter de se connecter aux systèmes observés.
