# Fact-check local — Vallée des Aldudes

Dernière vérification : **2 septembre 2026**.

Ce document verrouille les formulations locales du cours. Les faits peuvent être actualisés, mais une séance ne doit jamais transformer une hypothèse pédagogique en caractéristique réelle du territoire.

## Règle pour S2–S5

Les éléments suivants restent **scénarisés** tant qu’une source datée ne les établit pas :

- qualité de couverture 4G/5G/LPWAN sur un point précis ;
- absence d’électricité sur un site ;
- emplacement d’un capteur, d’une passerelle ou d’une caméra ;
- panne réseau ou coupure d’énergie ;
- délai d’intervention ;
- existence d’un dashboard territorial ;
- décision automatique déjà déployée ;
- coût réel d’un dispositif fictif.

Quand un incident pédagogique utilise l’un de ces éléments, l’interface doit le présenter comme **information de mission / hypothèse / incident**, jamais comme un fait territorial établi.
