# IoT Systems Design — Session 1

Student-facing GitHub Pages workspace.

## Public student URL

Publish this folder at `cours/iot/`. The student workspace is `index.html`, so students can simply open `/cours/iot/`.

- `index.html` — student workspace
- `student.html` — compatibility redirect to `./`
- `assets/styles.css` — shared styles
- `assets/student.js` — local-only interactive logic
- `SOURCES.md` — technical source notes

The teacher guide is intentionally stored outside the student folder at `cours/instructor/iot/`. It remains public on GitHub Pages if somebody knows the URL; GitHub Pages does not provide access control.

The student site uses no backend or database. Work is saved in browser localStorage and can be exported/imported as JSON.
