What changes when the system can act?

Extend your reasoning from monitoring to a closed loop. Decide which elements are necessary to make a command defensible — and which evidence tells you that the physical action really happened.

The service may command ventilation. A human operator can override the automation. The actuator can fail mechanically even when the command was delivered correctly.

Campus missionYour flows now need communication paths.Do not choose a technology yet. First understand the shapes of networks that could carry those flows.

Start from the communication problem — not from a standard name.

You are not expected to know Wi-Fi, Bluetooth LE, IEEE 802.15.4, LoRaWAN or NB-IoT yet. First learn the shape of the network each family is trying to build.
