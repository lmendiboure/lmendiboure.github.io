Activity 1Describe the conversation
START WITH BEHAVIOUR

What must happen between the two sides?

Before choosing MQTT, CoAP or HTTP, describe the exchange in ordinary language: who starts, who receives, and must anyone wait?

WORKED EXAMPLE · B204 CO₂ TELEMETRY
Sensor has a new sample→sends it→continues measuring

One sender produces information without waiting for a reply. We can now name that behaviour: one-way push.

Keep the questionWho initiates? One receiver or several? Must someone wait before the exchange is complete?

Conversation first. Protocol later.

COMPAREWhich property actually changes the conversation: initiator, receiver set, or waiting for a reply?
Interaction pattern

A compact name for service behaviour: one-way push, request/response, publish/subscribe, command/acknowledgement. It does not choose the implementation protocol yet.

Activity 2Make the order visible
ONE EXCHANGE · ONE SEQUENCE

A command is more than an arrow.

A controller asks ventilation to change. Put the three events in a defensible order. The point is to distinguish a digital receipt from evidence of the physical result.

WORKED EXAMPLE · REQUEST / RESPONSE
Dashboard asks for room status→service returns the status

This ordered view is a message sequence. Engineers often call the ordered exchange a choreography.

Ventilation command · click the next event

Activity 3Four jobs in the path
STOP SAYING “THE NETWORK”

What different jobs are hidden inside communication?

Use four responsibilities only. This is the mental model we will reuse for the rest of the session.

ApplicationWhat does the message mean and how is the service used?
TransportHow do two programs exchange a stream or datagrams?
NetworkHow do packets reach a destination across networks?
Local accessHow does data cross the immediate Wi-Fi / radio / wired hop?
Not a fifth job todaySome constrained links need an adaptation mechanism between IP and the local radio. We will point to 6LoWPAN when Thread appears, but you do not need a separate “adaptation layer” to reason through this session.

A stack is an ordered set of responsibilities.

BOUNDARYWhat would be wrong with comparing a technology that defines application messages with one that only moves packets?
Compare within a job. Compose compatible mechanisms across jobs.

Application, transport, network and local access answer different questions. A technology suite can span more than one row.

Under the hood: where does 6LoWPAN fit?

On low-power IEEE 802.15.4 links, 6LoWPAN adapts IPv6 to small frames using mechanisms such as header compression and fragmentation. It matters technically, but it is not a new decision students need to manipulate in the core route today.

Class discussion

Protocol choice starts from service behaviour.

COMPAREWhich two choices are genuinely alternatives, and which could coexist in one end-to-end path?
Application protocol ≠ complete stack.

MQTT, CoAP and HTTP define application exchanges. They still rely on transport, network and local-access responsibilities below.

Activity 6Compose — then check compatibility
BUILD → AUDIT → TRANSFER

Different responsibilities can compose. That does not make every combination valid.

Build one end-to-end path, then audit a deliberately questionable stack and test what can remain unchanged when only the local access path changes.

RuleCompare candidates that solve the same responsibility. Compose mechanisms across responsibilities — but still check that adjacent mechanisms expose compatible interfaces and assumptions.
Activity 7Make the payload usable
THE BYTES ARRIVED

Why is {"value":812} still not enough?

The network and application protocol succeeded. Repair the data contract so another system can interpret the measurement without guessing.

RECEIVED{"value":812}
Three different identifiersNetwork address tells packets where to go. A URI/topic names an application resource or channel. A semantic contract tells the receiver what the data means.
STOP
Class discussion

Delivery is not understanding.

CHALLENGETwo devices both send {"value":25}. One means 25 °C and one means 25 %RH. What layer succeeded, and what contract failed?
Interoperability includes shared meaning.

Successful byte/message exchange is necessary but not sufficient. Quantity, unit, source and time are part of a usable data contract.
