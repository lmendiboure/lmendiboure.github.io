Session synthesis

A protocol name is not the architecture, delivered bytes are not shared meaning, and “reliable” only makes sense once its object and scope are explicit.

Service need→Interaction pattern→Choreography→Message meaning→Stack responsibilities→Protocol composition→Delivery semantics→Failure test
Patterncomes before protocol choice.
Choreographyis not topology.
Stackorders responsibilities before names.
Meaningis more than delivered bytes.
Compositioncompares within roles and combines across roles.
Guaranteemust name its object and scope.
Failureis traced end-to-end, not blamed on one “reliable” protocol.
