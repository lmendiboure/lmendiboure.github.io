What carries the application exchange?

Use these simplified reference paths. We are learning where the mechanisms sit; later courses can explore every protocol variant.

TCPOrdered, reliable byte stream between programs.

Local pathThread over IEEE 802.15.4
Term introduced here — not before

Thread is an IPv6-based low-power mesh networking stack using IEEE 802.15.4 radios. For today, the important point is where this constrained local path sits in the complete communication map.

Important nuanceReal technology suites do not always fit perfectly inside one row. The rows represent responsibilities; “Thread over 802.15.4” is our shorthand for the constrained local connectivity path. Other Session 1 families can insert gateway or network-service infrastructure rather than exposing this exact stack end-to-end.
