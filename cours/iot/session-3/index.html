BOUNDARYWhen did proximity actually constrain your placement — and when was remote execution still perfectly acceptable?
Start from the response budget, not from a preferred zone.

Nearer execution can reduce communication delay, but only a stated latency or locality requirement makes that advantage decisive.

Activity 5Minimise what crosses a boundary

Raw data does not always need to leave the site.

New requirement: estimate room occupancy from a camera. Raw images may not leave the building, the camera device cannot run the model, and a small building server is available.

Choose a pipeline and the data that crosses the building boundary.
STOP
Class discussion

Placement also decides what data leaves a trust boundary.

COMPAREWhat did you gain by moving computation toward the data source — and what new local resource did you have to rely on?
Data minimisation can be a placement objective.

Processing near the source can replace high-volume or sensitive raw data with smaller derived information — but it consumes local compute and creates a new execution dependency.

Activity 6What changes when a gateway starts computing?
NAME THE ROLE AFTER YOU SEE THE WORK

The same nearby box can play very different roles.

Compare two deployments. Mark which application functions moved from remote infrastructure into the nearby node.

DEPLOYMENT A

Gateway forwards

sensor → gateway → remote service

The gateway translates/forwards traffic. Filtering, decisions and short-term state remain remote.

DEPLOYMENT B

Nearby node computes

sensor → nearby node → remote service

The nearby node filters, detects local conditions and keeps a short cache before forwarding summaries.

Now we can name the idea.

In Deployment B, the nearby node is taking an edge-computing role: application work is executed closer to the data source instead of only in remote infrastructure. “Edge” describes a placement role; it is not one mandatory box or protocol.

Identify the three functions that moved.

DEFENDWhere did your pipeline change representation or responsibility, and which constraint justified that cut?
Split systems need explicit cut points.
