# Session 3 — sources and technical anchors

## NIST

- NIST SP 500-325, *Fog Computing Conceptual Model* (2018): https://www.nist.gov/publications/fog-computing-conceptual-model
  - Useful for the relationship between IoT data management, decentralised/fog computing and cloud models.
  - Instructor use: supports the idea that moving computation/data services away from a purely central cloud model is motivated by system constraints, not by a single product category.

## ETSI

- ETSI GS MEC 003, *Multi-access Edge Computing (MEC); Framework and Reference Architecture* — current ETSI work item/version information: https://portal.etsi.org/webapp/WorkProgram/Report_WorkItem.asp?WKI_ID=72076
  - Useful as a precision note for instructors: MEC is a specific multi-access edge framework. It should not be used as a synonym for every nearby IoT gateway or local compute node.

## Teaching note

The core student route intentionally uses **device / nearby / remote** before formal edge terminology. This is a pedagogical abstraction, not a claim that all standards use the same three-layer taxonomy.
