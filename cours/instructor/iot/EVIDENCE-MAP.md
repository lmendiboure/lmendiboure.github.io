# Evidence map for the reusable learning-design pattern

This document maps each major design mechanism to research that motivates it. It also states the limits of the inference: the literature supports the **underlying instructional principle**, not necessarily this exact web implementation or sequence.

| Design mechanism | Intended cognitive function | Research basis | What we can reasonably claim | What we should not claim |
|---|---|---|---|---|
| Students classify/design/decide before listening to a long explanation | Active engagement and generation | Freeman et al. 2014; Chi & Wylie 2014 | Active/constructive/interactive learning is generally preferable to passive-only instruction in STEM contexts | That every unguided discovery task is beneficial |
| Student artifact visible at STOP | Externalise reasoning; support explanation and comparison | ICAP; self-explanation research | Generating/explaining/comparing can support deeper learning | That a visual artifact alone causes learning |
| LOOK → COMPARE → CHALLENGE → UNLOCK | Move from generated ideas to feedback and formalisation | ICAP + scaffolding/example research | Generation plus guided formalisation is defensible for novice instruction | That “productive struggle” should be prolonged without support |
| Plain-language network shape before PHY/MAC/RAN/etc. | Reduce unnecessary initial load; build schema before terminology | Cognitive load / worked-example literature | Novices benefit from stronger guidance and well-structured examples | That jargon should never be taught explicitly |
| Progressive disclosure / collapsible technical depth | Segment information and allow learner-controlled depth | Cognitive-load/segmentation principles; autonomy considerations | Layering can reduce first-contact information density | That optional content will automatically be learned by everyone |
| Soft linearity: future gated, past reviewable, explicit return to frontier | Support reflection while limiting disorientation and premature access | Learner-control / hypermedia reviews (Scheiter & Gerjets 2007; Karich et al. 2014) | Learner control is not uniformly beneficial; structured navigation and support are defensible, especially for novices | That free navigation itself improves learning, or that this exact gating rule has an isolated causal effect |
| One persistent campus case | Context and coherent problem representation | Case-based/problem-based learning evidence | Cases can support knowledge/skill development when well facilitated | That one case alone ensures transfer |
| Multiple transfer cases | Abstract principle from surface context | Analogical/example-based learning; desirable-difficulty/variation literature | Varying contexts can help learners discriminate underlying structure | That maximal variability is always better |
| Commit answer + decisive assumption + confidence | Self-explanation and metacognitive calibration | Self-explanation research; ICAP | Requiring reasons generates more cognitive work than answer-only clicks | That confidence calibration will become statistically well calibrated without repeated feedback |
| Changed assumption / counterexample | Test over-generalised rules and validity domains | Variation, desirable difficulties, transfer-oriented instruction | Carefully chosen difficulty can improve durable discrimination | That making a task harder is inherently beneficial |
| Adaptive depth (`Core → Challenge`) | Match instructional assistance to prior knowledge while preserving one shared objective | Expertise-reversal effect; fading-guidance logic | Low-prior-knowledge learners generally benefit from higher assistance, while higher-prior-knowledge learners can benefit from lower assistance | That speed is a valid proxy for expertise, or that novices should receive less support |
| Beat the scaffold (progressive optional supports) | Self-regulate assistance without forcing a separate track | Expertise-reversal + structured learner-control logic | Offering optional support can operationalise differentiated assistance while keeping the novice route intact | That zero hints is inherently better or should be graded |
| Research trail: prediction → official source → reconciliation | Authentic disciplinary inquiry, evaluation of a claim, self-explanation | Self-explanation / source-use logic; adaptive-expertise aims | Primary/official sources can deepen the same objective when learners use them to resolve a question | That extra reading benefits fast learners merely because it is harder or longer |
| Field Guide after discussion | Formalisation and persistent reference | Scaffolding + retrieval/review design | A concise reference after generation prevents leaving concepts implicit | That reading the guide replaces retrieval practice |
| Architecture v1 → v2 | Make conceptual change observable; require application | Active/constructive engagement; case/problem solving | Revision requires students to use new information on a prior artifact | That visible revision alone measures conceptual understanding perfectly |
| Memory Lock before synthesis | Retrieval practice | Roediger & Karpicke 2006; Karpicke & Blunt 2011 | Retrieval supports longer-term retention and meaningful learning | That four immediate questions guarantee long-term retention |
| Live Board: Capture / Structure / Compare | Make selected student reasoning externally visible in a task-matched representation | Visible-thinking/documentation logic; concept-mapping review; multiple-external-representation research; peer-instruction sequencing | External representations and structured class response can support comparison and discussion when the representation is meaningful and supported | That more visualisations are always better, that a class majority is correct, or that this specific three-widget implementation has an isolated causal effect |
| Mission / incidents / depth trail / unlocks | Motivation and coherent gameful framing | Gamification meta-analyses | Gamification can support outcomes/motivation, with heterogeneous effects depending on design | That points, badges or “game feel” are inherently effective |

## Post-activity consolidation / instruction after exploration

**Design implication used here:** after students externalise and compare tentative models, follow with explicit consolidation that links their evidence to disciplinary language and an actionable rule. The implementation uses **From your discussion → Formalise it → Carry it forward**.

**Claim boundary:** the exact three-label UI sequence is a local design synthesis, not a separately validated instructional protocol. Its rationale is the broader evidence for active generation followed by well-timed instruction/consolidation, self-explanation and comparison.
